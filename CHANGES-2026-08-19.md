# Master Sheet cleanup + site rewrite — Aug 19, 2026

## 1. Excel cleanup (`MasterVendorList-cleaned.xlsx`)

Source: `8-18-MasterVendorList.xlsx`, 16,801 rows → 16,666 rows after cleanup.

- **States**: normalized casing/whitespace (356 cells) and fixed the
  "Deleware" → "Delaware" typo (82 rows).
- **Cities**: trimmed whitespace (16 cells), stripped a trailing " -"
  artifact from one NC vendor's coverage list (12 rows), and corrected
  25 verified misspellings (e.g. "Nort Port" → "North Port",
  "Cincinatti" → "Cincinnati"). This was **not** a blanket fuzzy-match
  pass — an automated pass found ~1,500 similarly-spelled city pairs
  across the sheet, but most are genuinely distinct real towns (e.g.
  "North Lauderdale" vs "Fort Lauderdale" are both real, separate FL
  cities). Only pairs independently verified as real typos were
  touched; everything else was left alone rather than guessed at.
- **Container sizes**: fixed 171 cells missing the "D" in a real-size
  annotation, e.g. `(12Y)` → `(12YD)`.
- **Price ranges**: 12 cells replaced with the higher number in the
  range. One cell (`$486-55/2T/?`, Port Jervis NY) was left untouched —
  the second number is *lower* than the first, so it's not a real range,
  it's garbled data. Flagging for your review rather than guessing.
- **Sales Tax Rate**: every row is now a clean decimal fraction (e.g.
  `0.0925`), ready for direct use in the pricing formula — no more
  descriptive text. 1,526 rows that said "Verify locally" were filled
  with that state's most common resolved rate among the sheet's other
  rows, each flagged with a cell comment noting it's an estimate.
- **Duplicates**: 135 fully identical rows removed (the one case where
  rows were actually deleted, since they carried no unique information).

**Still open, not touched this pass:** the ~110 vendor+city groups with
genuinely *conflicting* (not identical) data — e.g. Greenway Dumpster's
inconsistent $50 delivery fee across Indiana cities, Gulf Coast's two
different Naples ton rates. These need your judgment call on which
number is right, not an automated fix.

## 2. Site logic rewrite

- **`tools/convert-vendor-sheet.py`** — fully rewritten for the real
  Master Sheet's column layout (previously built for the 412-row filler
  sheet's different columns). Handles:
  - Debris-type routing: `Standard Mixed` / `Standard CnD` and
    `Flat Rate Residential` / `Flat Rate CnD` tag a `debrisType` of
    `mixed` / `cnd`. A generic `Standard` or `Haul + Disposal` row with a
    populated CnD Waste / Mixed Waste column gets split into a
    debris-tagged sibling (using that column's rate) *plus* the original
    generic row stays as fallback for any other debris type.
  - `Haul + Disposal Commercial - See container size for price`: haul
    rate is now parsed per-size from each size cell's own
    `"$X Per Haul"` text, instead of one shared rate.
  - The `Other` column's per-ton and per-day overage rates are now
    extracted independently — a single cell very often has both
    (`"$35 Per Ton $10 Per Day"`, ~5,989 rows), which the old parser
    would have only caught one of.
  - Fuel Surcharge: flat dollar, percentage, or both in the same cell
    (`"$25 + 20% on disposal costs"`) are all parsed out.
  - Rows with no Pricing Model at all (6 rows) are dropped entirely —
    same as no vendor existing for that row.
  - A `(12YD)`-style real-size note is kept as an admin-only reference
    field rather than discarded.
  - **1,405 size cells across 38 vendors could not be parsed** and were
    skipped rather than guessed at — mostly literal `"?"` placeholders
    (American Disposal, MN — no price was ever recorded), the word
    `"Call"` in place of a number (D&D Trash, IN), and a handful of
    vendors that pack two debris-specific prices into one cell in
    inconsistent formats (Gaston Recycling, Dans Rubbish). Worth folding
    into the planned Excel cleanup session.

- **`js/quote-engine.js`** — real per-vendor tax rate (was a hardcoded
  0% placeholder), percentage fuel surcharges applied against the
  container base price only, and the debris-type filter/grouping logic:
  no debris selected shows every priced variant for a vendor+size
  grouped into one card with a label per price line; selecting CnD or
  Mixed collapses to the one matching price (its generic fallback is
  dropped once a more specific match exists); Concrete/Shingles/Yard
  Waste currently behave like "any" since no vendor data distinguishes
  them yet.

- **`js/sales.js`** / **`js/admin.js`** — updated to render the grouped
  debris cards with badges, and to show the new admin-only fields (split
  fuel surcharge, real tax rate, real container size note, a
  "DO NOT PRICE QUOTE" warning badge that was previously defined but
  never actually rendered).

## 3. Known trade-off worth a look

`js/data.js` is now **~22 MB** (51,667 pricing rules, one per
vendor/size/debris-variant combination) — up from a few KB on the
filler sheet. It'll still load in a browser, just not instantly on a
slow connection, and it's a lot of scrolling if anyone ever opens the
file directly. If that becomes a problem, the fix is restructuring the
data format (e.g. splitting by state, or a lighter columnar format)
rather than anything about the pricing logic — a separate conversation
whenever it's worth prioritizing.
