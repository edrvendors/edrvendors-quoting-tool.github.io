# Stress-test fixes — Aug 20, 2026

Built against `MyMasterVendorlist_new_.xlsx` (your edited sheet — 16,807 rows,
141 rows have no Pricing Model and are correctly dropped as "no vendor").

## Bugs fixed

1. **Norris Container / Brooker, FL** — two real bugs in the notice-banner
   logic:
   - It required a state to be entered before showing any must-call/
     franchised banner at all, even though the priced-results search never
     had that restriction. Fixed to work off city alone, same as
     everything else.
   - It wasn't filtering by the selected container size, so a vendor
     offering "must call" on 4 sizes produced 4 banners regardless of
     which size was picked. Now filtered by size and deduplicated by
     vendor.

2. **"No vendor" behavior (Littleton, CO)** — previously fell back to
   showing real vendor prices from elsewhere in the state, which you
   didn't want. Replaced with: a computed state-average **estimate** per
   size (Standard-model rows in-state only, +15%, taxed at the state's
   highest listed rate, ÷0.74, flat 7-day rental), visually distinct from
   a real quote, plus a separate contact-only card (name + phone, no
   price) for a vendor in the state worth calling to check. No size gets
   an estimate if the state has no Standard-model data to average from,
   rather than guessing.

3. **Haul + Disposal per-size pricing (Rocky Mountain Roll Off, Denver, and
   others)** — your updated sheet signals "price is per container size"
   through the Haul Rate column text ("see container size rate") rather
   than always through the Pricing Model name, and a "Flat" Tonnage Rate
   means no per-ton charge applies at all. Neither was handled. Also found
   ~50 different cell formats in this category sheet-wide (with/without
   "$", with/without "Per", "Haul" vs "haul", embedded per-ton/delivery
   overrides in the same cell, a bare "Available" meaning must-call for
   just that one size, real-size prefixes without parentheses). Rebuilt
   the parser to extract each field independently instead of one rigid
   pattern. 242 "Available"-only cells (9 vendors) now correctly become a
   size-scoped must-call notice instead of being silently dropped.
